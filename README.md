# 🍵 Çay Ocağı Tycoon

Tarayıcıda oynanan bir dükkân işletme oyunu. Küçük bir mahalle çay ocağını devralıp onu şehrin en ünlü mekânına dönüştürüyorsun.

## Nasıl oynanır?

`index.html` dosyasını tarayıcıda açman yeterli; kurulum gerekmez.

1. Müşteriler kapıdan girip masalara oturur, siparişleri balonda görünür.
2. Tezgâhtaki ürüne tıkla (veya 1-6 tuşlarına bas). Ürün ocakta hazırlanıp tepsiye düşer.
3. Müşteriye tıkla; tepsideki uygun ürünler servis edilir.
4. Kazandığın parayla dükkânını geliştir.

## Özellikler

- **Canlı dükkân sahnesi:** Mini insanlar yürür, oturur, sipariş verir. Mutlu müşteri bahşiş bırakır, sabrı tükenen kızıp gider.
- **Dükkân sahibi:** Adını, dükkânın adını ve karakterinin görünümünü (ten, saç, gömlek, bıyık) seçebilirsin.
- **Dükkânı büyüt:** Dükkân para ve zamanla dört seviyede büyür: Mahalle Çay Ocağı → Kıraathane → Nostaljik Kafe → Ünlü Mekân.
- **Geliştirmeler:** Masa, tepsi, semaver, dekorasyon, neon tabela, çırak ve garson.
- **Özel olaylar:** Maç günü, yağmurlu gün, bayram, VIP müşteri, influencer, turist kafilesi, elektrik kesintisi, mutlu saat.
- **Sesler:** Hepsi Web Audio ile üretilir, ses dosyası gerekmez.
- İlerleme tarayıcıda (localStorage) otomatik kaydedilir.

Tek bir HTML dosyasından oluşur; saf HTML, CSS ve JavaScript (Canvas) ile yazıldı.
